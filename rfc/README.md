# RFC index

RFCs describe intended contracts and open obligations. Their status headers
and experiment sections distinguish implemented subsets from proposals. Start
with [project status](../STATUS.md) and [objectives](../doc/objectives.md) for
the current implementation and longer-term direction.

| RFC | Topic | Implemented boundary |
|---|---|---|
| [0001](0001-forks-and-authority.md) | Forks and authority | T0 enforcement; general authority-store theorem and durable rights recovery remain open |
| [0002](0002-effects-and-handlers.md) | Effects and handlers | T0 handlers and selected compiled paths; general compiled capture remains open |
| [0003](0003-licensed-specialization.md) | Licensed specialization | Guarded checked recipes and bounded guest planning; statistical contracts remain proposed |
| [0004](0004-canonical-edn.md) | Identity and serialization | Representation-sensitive Core IDs and restricted deployment codec; portable common codec remains proposed |
| [0005](0005-affine-regions.md) | Affine regions | T0 ownership and bounded checked/native inference; arbitrary functional-to-affine translation remains open |
| [0006](0006-languages-as-world-values.md) | Languages as world values | Syntax objects, local expansion and grammars; general semantic descriptors remain proposed |
| [0007](0007-modules-and-abstract-identity.md) | Modules and abstract identity | Draft |

Historical implementation reports retain the evidence for their own source
snapshots; a passing old experiment is not a current general correctness claim.
