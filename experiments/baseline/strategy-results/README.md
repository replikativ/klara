# Funded strategy consolidation

`before/` preserves the source of the hosted recipe/preparation adapters before
the subject/checked-edge/strategy consolidation. It is a source cohort, not a
timing comparison. Current implementation and limits are documented in
[preparation strategies](../../../doc/engineering/preparation-strategies.md).

`clojure -M:test` exercises the strategy, distinct policy/reference roots,
forged-edge rejection, persistent funding, runtime policy changes and decline
without publication. `clojure -M:verify` includes the fork-replay admission
rejections. Its generated report records current source hashes.

The sibling `runtime-optimizer-results/normalized-final.edn` records the
legacy planner lifecycle after normalized declines. Earlier reports retain
their original exception behavior and source hashes.
