# S3: map/filter/reduce fusion with ansatz certificates (2026-10-27)

Implements step S3 of `06-architecture-synthesis.md` §7: the first wandler idea
reimplemented on Klara. A pipeline written in Klara is elaborated **from Klara
core terms** into an ansatz CIC term, fused by two laws proved in ansatz, and
lowered to a host function. The function is installed through `klara.stage`
under (CodeId, guards) with a certificate that `install!` rechecks in the
kernel. Editing a stage sends the next call to the generic path, and
re-optimizing produces a new certificate.

```
clojure -X:test        # 36 tests, 3226 assertions, 0 failures (S1: 29 tests; S3: 7)
```

Dependencies: `org.replikativ/ansatz 0.2.115` from Clojars, the version wandler
pins, so the differential test runs both on one kernel. `../wandler` is a
`:local/root` in the `:test` and `:nrepl` aliases only; `src` never requires it.

REPL-level use (this is `edit-a-stage-then-reoptimize`):

```clojure
(def S (f/session))
(f/define! S '(def keep? (fn [x] (even? x))))
(f/define! S '(def p (fn [xs] (reduce + 0 (map (fn [x] (* x x)) (filter keep? xs))))))
(f/optimize! S 'p)                ;=> {:status :generic :reason :no-shape-claim}
(f/claim! S 'p '{:args [(List Nat)] :ret Nat})
(f/optimize! S 'p)                ;=> {:status :fused :stages [:filter :map :reduce]
                                  ;    :laws ["Klara.foldl_map" "Klara.foldl_filter"]
                                  ;    :theorem "Klara.fusion.5cf8300d2a25bf17" :guards #{..}}
(f/run S '(p [1 2 3 4 5 6]))      ;=> 56, through the executable
(f/define! S '(def keep? (fn [x] (odd? x))))
(f/run S '(p [1 2 3 4 5 6]))      ;=> 35 at once: the [:world keep? ..] guard fails, generic runs
(f/optimize! S 'p)                ;=> a new theorem, a new guard set, same CodeId
```

### Elaboration (scope 1)

`elaborate` reads the Klara core term of the pipeline fn. `map`, `filter` and
`reduce` appear there as `:host/call` performs of `clojure.core/…`, and `+` in
value position appears as `:host/var`. The supported fragment:

- **Pipeline:** `(fn [xs] (reduce F I S))`, or `(reduce + S)` / `(reduce * S)`
  (init 0 or 1). `S` is any chain of `map`/`filter` ending at the parameter.
- **Stage:** an inline fn, a world definition holding a fn (inlined; its
  version becomes a guard), or a prim in value position.
- **Stage body:** locals, non-negative integer and boolean literals, `if`,
  `let` (by substitution, which is sound because the body is pure), calls of
  elaboratable world fns, and the prims
  `+ * inc quot rem mod < > <= >= = not= zero? pos? even? odd? not identity`.
  `and`/`or` work through their host-macro expansion to `let`/`if`.
- **Typing:** typed by construction over `Nat`/`Bool`. The kernel types the
  result.

**Gating.** Nothing is elaborated without a shape claim. `claim!` publishes the
world definition `p$shape`, and only `{:args [(List Nat)] :ret Nat}` is
supported. The claim is checked in two places. Its argument part becomes the
entry guard `[:arg 0 :nat-list]`: nil, or a realized vector or list of
non-negative Longs, so lazy seqs, negatives and doubles go generic. Its result
part is checked when the kernel types the elaborated term. Unclaimed code stays
generic.

**Opaque stages.** Anything outside the fragment makes its stage opaque, and
fusion stops there: an effect (`println`), a host call, `-`/`dec`, a
non-literal callee, or a recursive helper. `optimize!` then reports, for example,
`[:opaque-stage 0 :map [:prim dec]]`. Elaboration is the purity check: a stage
that elaborates is an ansatz term.

### Laws (scope 2)

Both laws are polymorphic in universe 0, proved by `List.rec` with the
accumulator generalized, and kernel-checked when the proof Env is built:

```
Klara.foldl_map    : foldl f b (map g l)    = foldl (λ acc x. f acc (g x)) b l
Klara.foldl_filter : foldl f b (filter p l) = foldl (λ acc x. cond (p x) (f acc x) acc) b l
```

In the filter case, `Bool.rec` splits on `p hd`. The motive writes
`filter p (hd::tl)` as `cond c (hd :: filter p tl) (filter p tl)`, which is
definitionally equal at `c := p hd`. No Init lemma is cited, so the laws check
against ansatz's bundled medium Init tier (3653 declarations, which lacks
`List.foldl_map`). No external store is needed. A wrong statement, the filter
law with its `cond` branches swapped, is rejected (tested).

`fuse` absorbs the outermost stage at each step: one law instance per stage,
chained with `Eq.trans`. The steps are β-normalized. The result is a theorem
`∀ xs : List Nat, naive xs = fused xs`, where `fused` is one `List.foldl` over
`xs`. Per-pipeline theorems are **checked but never admitted** into an Env.
They are named `Klara.fusion.<goal-hash>`, which sidesteps redefinition
(v2 §11) entirely.

### Overflow (doc/06 §4)

The laws hold over `Nat`, but the code runs on longs. The obligation splits
into four parts:

1. **Exact-or-throw lowering.** Each Nat operation maps to a JVM operation that
   returns the Nat result or throws: `Math/addExact`, `multiplyExact`,
   `incrementExact`, `quot`, `rem`, and exact comparisons. `Nat.sub` is never
   produced, because `-`/`dec` are opaque. Literals must fit in 62 bits.
2. **Deopt.** The executable catches `ArithmeticException` and returns
   `klara.eval/deopt`. The generic path then runs from entry. Replay is sound
   because the stages perform no effects. *So whenever the executable returns a
   value, that value is the Nat meaning of the fused term, which the theorem
   equates with the Nat meaning of the naive term.*
3. **The generic path** uses clojure.core arithmetic. On non-negative longs it
   is also exact-or-throw, so it either throws or returns the Nat meaning of
   the naive term.
4. **Trusted gap.** Both paths must overflow on the same inputs. This holds
   because the rewrite is *operation-preserving*: per element, the fused step
   applies the same stage functions to the same values, so both paths perform
   the same multiset of arithmetic operations. The argument is recorded in the
   certificate as `:overflow-coincidence :status :trusted`. It is
   property-tested with inputs near `Long/MAX_VALUE`, where executables deopt
   and both sides throw `ArithmeticException`. It is not proved. A future law
   that changes the operations (e.g. `a*b/b → a`) would need a range guard or a
   proof over a bounded-integer model.

The effect side condition is new relative to wandler. `map`/`filter`/`reduce`
are ambient `:host/call` performs, and a dynamic handler can reinterpret them
(S1 decision 11). The executable is therefore guarded by
`[:unhandled #{:host/call :host/var}]`, checked against the caller's
continuation. Under a mocking handler the generic path runs and gives the
mocked answer (tested).

## 2. Certificate format (scope 3; v2 §11)

```clojure
{:code-id         "<CodeId of the Klara fn term>"
 :assumptions     #{[:captures []] [:arg 0 :nat-list] [:unhandled #{:host/call :host/var}]
                    [:world keep? "<value-id>"] [:world p$shape "<value-id>"]}
 :checker         :ansatz/kernel
 :checker-version "ansatz/0.2.115+klara.fusion/1"
 :provenance      {:specializer :klara.fusion/optimize :elaborator "klara.fusion/1" :source-term-id ..}
 :source          {:term <Klara core term> :claim {..}
                   :stages {keep? {:term <fn term> :value-id ..} p$shape {..}}}
 :laws            {"Klara.foldl_filter" {:type-hash .. :proof-hash ..} "Klara.foldl_map" {..}}
 :theorem         {:name "Klara.fusion.<16 hex>" :goal-hash .. :proof-hash ..}
 :lowering        {:form-hash ..}
 :side-conditions [{:condition :purity :status :by-construction} ..
                   {:condition :overflow-coincidence :status :trusted}]
 :cohort          {:source :ansatz/bundled-medium-init :resource "ansatz/init-medium.ndjson.gz"
                   :sha256 "1fa6384e…" :declarations 3653}
 :closure         {"Bool" "<decl-hash>" "List.foldl" ".." ..}   ; 26–125 declarations
 :payload         {:goal <Expr> :proof <Expr>}                   ; not digested; bound by hashes
 :digest          "<sha256 over everything but :digest/:payload>"}
```

`install!` runs S1's checks first: CodeId, assumption set, a registered
checker, provenance, digest. The `:ansatz/kernel` checker then rejects:

| Reason | Check |
|---|---|
| `:checker-version-mismatch`, `:cohort-mismatch` | the certificate names this kernel and this proof environment |
| `:law-mismatch` | each cited law's hashes equal the laws in the proof Env |
| `:source-mismatch` | `code-id(source term) = executable CodeId` |
| `:stage-mismatch` | each recorded stage term hashes to its value-id, and that `[:world s vid]` is among the guards |
| `:missing-guard` | the guards the theorem relies on are present: `:nat-list`, `:captures`, and `:unhandled` for exactly the performs of the source |
| `:source-does-not-elaborate`, `:goal-mismatch` | the goal is **recomputed** by re-elaborating and re-fusing the recorded source, never taken from the certificate |
| `:proof-hash-mismatch`, `:closure-mismatch` | the payload matches the hashes, and the dependency closure recomputed in the checker Env equals the recorded one, which detects a changed store |
| `:proof-rejected` | `env/verifies?`: the kernel's strict `check-constant` of the supplied proof against the recomputed goal |
| `:lowering-mismatch` | the executable's form equals the lowering of the recomputed fused term, and `:run` is the function compiled from that form by `klara.fusion/compile-form` (the only producer) |

All of these were exercised with forged certificates, including a
self-consistent one carrying another pipeline's proof (`:proof-rejected`).
Cost: specialize 2–11 ms, check 1.4–7.7 ms per pipeline, after the one-time
proof Env build (~1.4 s, mostly loading the bundled Init).

## 3. Tests (scope 4)

`fusion_test.clj`:

- `laws-are-kernel-checked`: both laws admitted and re-verified; a wrong
  statement is rejected.
- `a-la-carte-and-opaque-stages`: an unclaimed pipeline stays generic;
  `dec`, an effectful stage and a recursive helper each block fusion with a
  named reason; the generic path still runs, and the effect still prints.
- `fused-equals-generic-on-random-inputs`: 6 pipelines, 1 to 4 stages, with
  `if`/`and`/`quot`/`rem`/`inc`, no-init `+`/`*`, and a world-fn stage.
  300 seeded inputs, a fifth of them near `Long/MAX_VALUE`. Outcomes (value or
  exception class) are equal; hits > 0 and deopts > 0. Also covered: entry
  guards (negatives, doubles, `(range 5)`, a lazy `map` → generic; `nil`, `[]`
  → executable) and a dynamic `:host/call` handler (generic, mocked result).
- `edit-a-stage-then-reoptimize`: edit `keep?`, and the next call runs generic
  with the new predicate. Re-optimizing gives the same CodeId, a new theorem and
  new guards. The sweep drops the old executable. Editing `p` itself gives a new
  CodeId, and editing the claim makes the guard fail and `optimize!` refuse.
- `r3-deleting-the-cache-changes-nothing`: 300 runs equal with no cache, with
  a populated cache and after `clear!`.
- `install-rejects-forged-certificates`: §2.
- `differential-against-wandler`: the same pipelines as wandler `a/defn`s over
  `(List Nat) → Nat`, on the full Init export (`../wandler/test-data/init.ndjson`,
  replayed in trust mode, ~30 s; skipped if absent). Wandler certifies all six,
  and on 100 random inputs each, Klara-fused = Klara-generic = wandler.

  failure deopts before any effect (open, §5).

## 5. Decisions taken, and left open

Taken here:

1. The elaborator reads core terms, not surface forms, so macros and helper
   definitions are already resolved.
2. The laws are proved by explicit proof terms rather than tactics. In 0.2.115,
   `induction … generalizing` followed by `simp_all`/`rfl` did not close
   foldl_map; the hand terms check directly.
3. Per-pipeline theorems are checked, never admitted.
4. The proof Env is a value captured once from the bundled medium Init.
   ansatz's global session is restored, and wandler can switch it freely.
5. Host executables may *decline* (`deopt`); `eval` replays the generic path.
   This is sound only for executables that performed no effect.
6. The entry hook sees the continuation, which the `[:unhandled]` guard needs.

Open:

- **Segmented fusion.** An opaque stage currently blocks the whole pipeline.
  Fusing the elaboratable segments around it needs a `:klara` executable that
  calls back into the machine.
- **Claims as surface annotations** (`^{:shape ..}` or a `defshape` macro)
  instead of the `p$shape` naming convention.
- **Wider types** (`Int` with a proof-backed lowering of subtraction, records,
  maps) and list results (`into []`, `mapv`), which are wandler's `filterMap`
  laws.
- Whether the element guard should be folded into the loop (above), or
  replaced by a representation predicate on Klara's own vector type.
- Whether the operation-preservation side condition should be **proved**:
  state both paths over a bounded-integer model in ansatz, or prove the rewrite
  preserves an operation trace.
- Making the background re-optimization of the demo plan (W3) automatic. For
  now, `optimize!` is called explicitly.

## 6. Gaps

- **Trusted:** the Klara-term → ansatz elaborator (deterministic, re-run at
  install, differential-tested, not verified); the lowering table
  (exact-or-throw by inspection and tests); overflow coincidence (§1).
- **Cohort:** the bundled-resource sha and the per-declaration closure hashes.
  ansatz 0.2.115 predates `bundle.edn`'s cohort manifest, so the certificate
  records its own. The bundled tier is admitted in TRUST mode, so the closure
  fingerprints the declarations but does not re-check them.
- **R3** is tested on results and exception classes, not on effect traces. That
  suffices because fused stages are pure, and an effectful stage never fuses.
- **Executables** are effect-free by construction here (decision 12 holds).
  Nothing checks it for other producers.
- **Not measured:** R1, R2 and R5 under fusion.

## 7. Findings in wandler and ansatz (not modified)

- **wandler:** `(reduce + xs)` without init (`wandler.surface.collections/reduce-elaborator`,
  collections.clj:258) assumes three arguments. It passes `nil` as the
  collection, the accumulator type stays a metavariable, and
  `wandler.surface.common/univ` hands it to `TypeChecker.inferType`, which
  fails with `Type error: Unknown expression tag 12` (MVAR). The fix is a clean
  rejection or support for the 2-arity form. The differential test spells
  those pipelines with an explicit init.
- **wandler:** `pos?` is not in the surface vocabulary ("Unknown constant:
  pos?"). This is a vocabulary gap, not a bug.
- **wandler:** `test-data/init-store` no longer opens under 0.2.115: `init!`
  reports no manifest, and `storage/load-env` says "Branch not found". Its
  tests fall back to replaying `init.ndjson`.
- **ansatz 0.2.115:** no bug found that blocked S3. Tactic proofs of the
  foldl laws did not close (`rfl: sides are not definitionally equal` after
  `induction l generalizing b`). This was not pursued, since the explicit terms
  check, and it may be fixed on main.
