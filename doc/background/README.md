# Background: how the design was reached

This directory is the **history** of Klara's design, not its current
description. For the language as it stands, start with `../../README.md` and
`../guide/`.

- `00-design-space.md` — principles and early decisions
- `01-core-v1.md`, `01-core-v2.md` — the two design iterations (v2 is the
  basis of the current design; its decision logs remain valid unless the guide
  or an RFC says otherwise)
- `02-examples.md` — the first worked examples (provisional syntax) and the
  gaps G1–G13 they exposed
- `03-spindel-alignment.md` — mapping to spindel and sci
- `04-demo-plan.md` — the wandler-with-staging demo plan
- `research/` — research notes A–J
- `reviews/` — external critiques (Codex)
- `impl/` — implementation reports S1 (runtime slice) and S3 (certified fusion)
