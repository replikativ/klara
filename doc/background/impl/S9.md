# S9: compiler checkpoints join S7 deopt (2026-10-28)

S9 connects the S8 compiler to S7 frame states for one conservative
speculation region. T0 remains the oracle; no affine operations or checker
were implemented, and `src/klara/authority.clj` was not edited. No Clojure
Java sources were consulted.

## Built

1. `ir/freshen` copies named terms with fresh function, let, letrec and
   handler binders, preserving free references and opaque quotations.
   Scalar replacement applies it independently at each closure substitution.
   A structural regression fails on the former duplicated binders. **No
   observational counterexample to the former implementation was established.**
2. `compile.speculate` walks the original named function's top-level let
   spine, before inlining and PE. A final binary `+` with a trivial first
   operand gets a checkpoint. Its source path is both the resume position
   and the feedback site within the original CodeId. No generic frames are
   pending there, so `:kont` is empty. The emitted fast path checks Long
   before unboxing the first operand; if the second operand is trivial,
   it checks/unboxes both. Clojure's checked addition retains overflow
   errors. Complex second operands still execute once, after the guard.
3. The checkpoint contains the complete original lexical environment.
   Parameters and computed intermediates use live slots. Direct local
   closures use `[:closure source-path]`. Vector fields get fresh ordered
   let bindings, used both by scalar replacement and `[:vector slots]`.
   Aliases reference previously rebuilt locals. Other allocations remain
   live; a direct map/list/set binding declines checkpoint generation.
   A failed guard calls `eval/deopt!`; the existing materializer rebuilds
   T0 over the caller's continuation. No replay from function entry occurs.
4. `stage/with-cache` exposes the current cache feedback through a dynamic
   binding. After three deopts at a site, emitted code uses generic addition
   there, without another guard/deopt or recompilation. Feedback never
   licenses an unchecked unboxing. It remains outside the world.
5. `test.check` generates bounded, well-scoped syntax trees with shrinking:
   arithmetic, lets/shadowing, ifs, projected vectors/maps, duplicated local
   closure calls, bounded single self-tail loops, lexical tail/abortive
   handlers, and ordinary evidence operations. Counted probes interspersed
   in generated expressions record ordered traces. A separate generator
   produces host calls, escaping closures, general/dynamic handlers and
   non-tail loops that compilation must reject.

The executable exposes `:generic`, `:frame-states`, residual `:ir` and
emitted `:form`; its pass log starts with `:speculate` and a site count.
The tested checker version is `s9-1`; the certificate digests generic code
and frame states using S7's existing mechanism. This is finite test
provenance and trusted compiler code, **not a proof**.

## Obligations and checks

| Obligation | Check |
|---|---|
| Globally unique named binders survive duplication | `duplicated-closures-have-distinct-binders` examines copied IR; existing shadowing/closure corpus and generated programs compare against T0 |
| Only sound facts enable unboxing | JVM Long check immediately dominates each long coercion; non-Long values deopt, or use generic addition after poisoning |
| State names the exact generic position | pass walks original source paths and original environment order before transformations; existing install-time scope checks apply |
| Elided allocations are materialized | generated-frame test removes both closure and vector, then fails the guard; resumed T0 projects that vector and calls that closure |
| Prior effects happen once | Counted trace before failed guard is exactly one entry; generated traces cover multiple prefixes and errors |
| Authority is not duplicated/replayed | evidence is live, including inside a rebuilt vector and closure; spending before failed guard leaves 3/4, including a caller's adopted fork; no branch context is rebuilt |
| Feedback stops speculation | seven non-Long calls produce exactly three deopts; cache feedback is poisoned at the generated source path |
| Frame states cannot be silently changed | tampering yields `:frame-state-mismatch`; S7 checks frame shape and authority constants |
| T0 observations / R3 | 160 generated accepted functions × six inputs (0, 1, -2, 1.5, keyword, Long/MAX_VALUE), including values, error kind **and message**, ordered probe traces; assert cache hits and compare again after clearing |
| Rejected code stays generic | 50 generated rejected functions, compile error and empty cache checked, then three T0 input comparisons (escaping closures observed by calling them) |
| Unsupported checkpoints | map/set bindings, branches, loops and lexical handler bodies compile without a generated checkpoint |
| Entry validity and effect boundaries | existing S7 validity/deopt tests, S8 redefinition, wrong arity, dynamic exception resumption, traces, authorities and fork tests |

Seeds are 90210 and 901; shrinking reports the smallest failing syntax.
Depth is bounded at three and loop counts at six. Tests do not establish
termination, equivalence for arbitrary programs, or arbitrary host behavior.

## Measurements

`experiments/compiler/bench.clj` now includes an independently written
Clojure function for each existing benchmark. The lexical weight handler
is represented by a local Clojure function. All three results must agree
before measurement. Compiled Klara includes T0 entry, cache and guards;
Clojure is called directly. These four loop benchmarks have no generated
checkpoint: the guard generator deliberately does not enter loops or
handlers. They measure the existing compiling tier, not speculation speedup.

Run:

```sh
clojure -M -e '(load-file "experiments/compiler/bench.clj") (klara.compile-bench/run!)'
```

OpenJDK 25.0.1, Clojure 1.12.4; input 200; 100 warmup calls per path;
median of seven batches of twenty calls; median of five compilations.
Times below are milliseconds per call. Ratios are T0/compiled (higher is
faster) and compiled/Clojure (lower is faster, target approximately 1).

| Function | T0 ms | Compiled ms | Clojure ms | T0/compiled | Compiled/Clojure | Compile ms |
|---|---:|---:|---:|---:|---:|---:|
| Numeric loop | 0.86669 | 0.01795 | 0.00566 | 48.3× | 3.17× | 4.383 |
| Vector/map loop | 2.56563 | 0.02399 | 0.02626 | 106.9× | 0.91× | 8.424 |
| Local closure loop | 4.58199 | 0.05878 | 0.05206 | 77.9× | 1.13× | 7.324 |
| Tail weight loop | 1.38647 | 0.01450 | 0.00835 | 95.6× | 1.74× | 5.338 |

This final sample was taken after the test process finished. Compiled/Clojure
is 0.91–3.17×; the approximately 1× target is not met across the suite.

Raw output is in `experiments/compiler/s9-results.txt`. These are shared
machine measurements with short warmup, no confidence intervals and no
allocation profiler. They do not support a stable throughput claim or a
claim that the approximately 1× target is met on every benchmark.

## Explicit decisions and open decisions

- **Region choice:** source-aligned let spines first, with no pending
  frames. Broader checkpoints need a frame-producing normalization pass
  and source mappings through inlining, loops and handler lowering.
- **Feedback policy:** consult cache feedback at execution and switch to
  generic emitted addition after three failures. Recompilation, thresholds
  tuned by measurements and profile-guided site selection remain open.
- **State size:** keep the entire original lexical environment. Liveness
  pruning, sharing virtual object graphs, and reducing success-path live
  field retention remain open. Even unused vector fields execute once.
- **Certificate boundary:** structural checking plus finite differential
  evidence. An independent residual semantics or proof-producing compiler
  remains open; a digest does not prove correspondence of host code.
- **Performance:** direct Clojure calls are the baseline. More warmup,
  isolated processes, confidence intervals, allocation measurements and
  optimizing the cache/entry ABI remain open before throughput claims.

## Gaps

No checkpoint inside a branch, loop, initializer, inlined callee or active
lexical handler; no generated continuation templates, OSR or general effect
capture. No virtual map/set/record descriptors or partial escape analysis.
Unknown/frame-creating authority operations still stay in T0. General
calls, dynamic/return handlers, escaping functions and the other S8
unsupported forms remain outside the emitter. Speculation only unboxes
at the guarded addition, not throughout the function. The generator is
finite and intentionally small; it does not generate arbitrary world
histories, multi-shot resumptions, divergent programs or affine operations.
The naming regression demonstrates the violated invariant, rather than an
observational failure of the former compiler.
