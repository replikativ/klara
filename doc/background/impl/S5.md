## 2. Decisions

1. **Which semantics.** Level-indexed small-step reduction in the style of
   λ○ (Davies 1996) and MetaML (Taha; Moggi et al. ESOP 1999): `ev w n t l`
   is the outcome of `t` at level `l`, nothing reduces at `l ≥ 1` except
   under `esc`. The scope-extrusion check is BER MetaOCaml's dynamic one
   (Kiselyov, FLOPS 2014), as in T0.
2. **Fresh names, locally nameless.** A binder met at level ≥ 1 is opened
   with a fresh name from the configuration's counter: `lam b` becomes
   `nlam g b[gvar g/0]`. The n-forms bind no index. This keeps the S2
   substitution (closed values only, no shifting) and keeps evaluation
   contexts out from under de Bruijn binders, so effect continuations
   `k = E[var 0]` stay correct. Two earlier designs failed on paper: a
   generic `named` marker under the original binder breaks either
   substitution at depth 0 or the per-frame well-scopedness of effect
   continuations; re-abstracting after every step forgets names that a
   resumed continuation should revive.
3. **Liveness as an outcome.** `run1` is a bottom-up structural recursion
   and cannot see the context, so a splice returns `chk ns n e`; each n-form
   frame removes its names on the way up and the root decides. This is
   T0's "a declaring frame is on the continuation" exactly, including
   resumed continuations.
4. **CSP is substitution.** A level-0 value substituted under `code` is
   built like source. This matches T0's `lift` for data and closures over
   data; it differs where T0 refuses (code values, closures over generated
   variables). Recursive closures stay `fix` (opaque); capabilities are
   stuck `lift`.
5. **`run_` is a form** (T0: the ambient op `:stage/run`), because the spec
   has no dynamic handlers to reinterpret it.
6. **Out of the model:** `genlet`/`with-genletrec` (would need a store of
   insertion points), `lift` as an operation, `:stage/*` handlers, `:auth/*`.

## 3. Differential test: findings

69 programs; 65 agree, 4 differ deliberately (`known-differences` in the
test; the test fails if one of them starts to agree, or if anything else
disagrees). The translation (`tm->t0`) maps the spec's de Bruijn terms
index-for-index onto T0 core terms. It needed two adapters, both
**translation differences, not bugs**:

- *specialize*: the spec's is curried, `((p m) y)`; T0's partial application
  calls `(p m y)` with two arguments, which failed with "arity mismatch" on
  the curried translation. An uncurrying adapter fixes it.
- *handle*: the spec has one op clause that dispatches on the op tag; T0 has
  one clause per op name. A clause per op duplicated the clause, so its
  `esc`s ran once per op inside `code`. The clause is now let-bound once.

| Program | Spec | T0 | Classification |
|---|---|---|---|
| `:bad-perform-target` | `badTarget` | "unhandled lexical effect" | deliberate: T0's message covers both cases |
| `:csp-code-value` | nested quotation | stage error | deliberate: T0 refuses a code value used at level 1 without `esc` |
| `:csp-closure-over-code-var` | closure re-read at level 1 | `lift` error | deliberate, and T0 is the better behaviour: re-reading changes the closure's meaning (it returned the variable's code, the copy returns the variable) |
| `:eq-on-code` | `primType` | `false` | deliberate: T0's `=` is `clojure.core/=` |

**No T0 bug was found.** The staging programs cover brackets, nested levels,
level-2 binders, hygiene, CSP, build order of a handle's parts (clauses,
return, body), multi-shot resumption during a build, continuations resumed
after their handler returned, extrusion at splice and at run, and run of
open code inside the binder's extent. **No spec bug** surfaced in the
differential run either. The earlier spec mistakes were caught by the
proofs (well-scopedness of a frame under a binder) before any program ran.

## 4. Proofs and the kill rule

Determinism, progress modulo named stuck states (with scope extrusion),
preservation of well-scopedness across levels (`ev-ok`), safety and the
s-m-n law hold for the staged calculus. `run-quote` proves
`run_ (code t) → t` for escape-free binder-free `t`. The version with
binders is open: it needs `close g (t[gvar g/0]) = t` for fresh `g`, so a
freshness invariant on the name counter. About 3 h in total, against
S2's 3.5 h; the kill rule (2×) was not triggered. Dropped: `run1 t = val →
isVal t` (code values have a recursive value criterion).
