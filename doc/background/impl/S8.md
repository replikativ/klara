# S8: first compiling tier (2026-10-28)

S8 implements a **conservative subset** of T1 and the T2 front half. It
is not full coverage of the requested compiler tier. Compilation is an
explicit operation over values, with a Clojure-form backend, guarded cache
installation and T0 fallback. HotSpot supplies subsequent optimization.
No Clojure Java sources or upstream Typed Clojure files were consulted.
`eval.clj` and `stage.clj` are unchanged, avoiding the concurrent S7 work.

## Built

`klara.compile.core/compile-def` accepts a World or root, a definition
symbol and options (`:fuel`, default 10; `:inline-fuel`, default 4).
It returns the original CodeId, guards, host function, emitted form,
named residual IR, allocation/liveness analyses, pass log, compilation
milliseconds and a certificate of kind `:tested`. Install with the
existing `klara.stage/install!`; clear with `klara.stage/clear!`.

`:repl/compile sym` compiles and installs in a session cache and prints
passes, guard count and construction sites removed. `:repl/compiled`
lists installed entries, including entries whose guards may no longer
hold in the current world. Neither command modifies definition values.
The new guide chapter's two transcripts are executable tests.

Supported: fixed-arity functions; primitives, lets and branches;
single-function self-tail `letrec`; bounded inlining of closed, open-basis
world functions; local closure calls; vector and keyword-map scalar
replacement; lexical tail/abortive handlers without return clauses;
ordinary authority operations through the existing store. Compiled
functions can spend authority inside forks whose control remains in T0.

## Pass obligations and checks

| Namespace / pass | Input → output | Obligation and evidence |
|---|---|---|
| `ir/named` | de Bruijn K0 → fresh-name core | Unique names preserve binding during substitution. Nested/shadowed lambda corpus and local closures compare against T0. Quotes are opaque. |
| `inline` | named core → named core + guards | Inline only current definitions whose closure has no captures and no pinned basis. Each expansion adds `[:world sym value-id]`; depth fuel and a cycle set bound expansion. Redefinition/fork tests exercise fallback and old-basis execution. |
| `ir/lower` | named core → K1 | Classify each executable `perform`. A lexical clause with no continuation occurrence is abortive; one final direct continuation application is tail-resumptive; unknown cases are general. General operations are not emitted. Authority store operations have a fixed tail-resumptive whitelist. |
| `pe` | K1 → K1 | Constant propagation, trivial binding substitution, dead branches, literal primitive folding, beta reduction, `identity` elimination. Argument lets retain left-to-right evaluation; failed folds remain runtime operations. Fuel-bounded fixpoint. Generated numeric inputs, zero truthiness, errors and effect traces check this. |
| `escape` | K1 → K1 + evidence | Bidirectional transitive alias analysis and backward may-use sets adapted from raster; normalized-use analysis licenses all-or-nothing replacement. Only recognized projections/direct local closure calls are safe. Unknown calls, host calls, returns and captures escape. Field initializers stay ordered and execute even if unused. Alias, retention, capture, error and trace tests check this. |
| second `pe` | K1 → K1 | Simplify field bindings and beta-reduce local closures after replacement. Same obligations. |
| `emit` | K1 → Clojure forms → IFn | Preserve order and exact primitive meaning. Self tail calls emit `recur`. Lexical operations call local clause functions directly; aborts carry a fresh handler token and unwind only to that extent. Unsupported forms fail before installation. |
| `runtime` | evaluated authority arguments → value/error | Call `klara.authority/op!` with the enclosing T0 frames from `*outer-k*`. Emitted code creates no branch contexts. Spending, insufficient funds and fork settlement compare against T0. |
| `core` | definition → executable | Empty capture/static guards; no dynamic `:exn/raise` handler; all world assumptions checked at entry. Wrong arity declines before effects. Record inlined reads during definition-time execution. R3, redefinition, derived-value invalidation and resumable-exception fallback tests. |

No standalone dead-code or common-subexpression pass is necessary for
this subset. Only trivial bindings can be dropped; possibly failing
computations and performed effects are retained. In particular, scalar
replacement of `[(/ 1 n) 7]` followed by `second` still divides first.

### What was ported from raster

The source is Christian Weilbach's Apache-2.0 raster code at
`compiler/passes/scalar/{pe,inline,dce,cse}.clj` and `analysis/memory.clj`.
This is an adaptation to a much smaller named-map IR, not a verbatim port
of raster's descriptor/array/automatic-differentiation infrastructure.
The PE carries over propagation, trivial substitution and bounded
fixpoint iteration. Inlining uses bounded expansion and recursion checks.
Alias closure and backward liveness follow the memory analysis.

Verified source issue: `analyze-sexp-let` computes `escapes?` only from
`escapes-via-return?` and `escapes-via-closure-sexp?`; passing a value to an
unknown function is not counted. Klara instead requires every use to be
recognized as safe. A regression passes a vector to a function that stores
it, then projects it: analysis refuses replacement, compilation refuses
the unknown call, and T0 retains the entire vector. Host/higher-order,
closure-capture and alias-return variants are checked separately.

Liveness is retained as diagnostic evidence; it does not license mutation
or buffer reuse. Scalar replacement relies on the stronger universal-use
check after alias propagation. No claim of ownership or uniqueness of
arbitrary host values is made.

## Certificates and observation boundary

These passes are **tested, not proved**. `:klara.compile/tested` validates
certificate kind/version and executable shape after the existing cache's
digest/CodeId/assumption checks. It is a trusted compiler checker, not an
ansatz theorem, a cryptographic binding of host code to source, or a
per-user-function exhaustive test. Provenance names the differential suite.

The corpus covers arithmetic, guide-style closures and loops, vectors and
maps, tail/abortive effects, errors, authority spending and forks. Numeric
inputs vary with a fixed random seed. Trace tests use host `Counted`
values to record clause computations in order, including abort and failure
prefixes. This observes effects without adding a compiler-only tracing API.
The same corpus also runs after deleting all executables, and checks cache
hits first so a silent blanket fallback cannot pass as compilation.

## Measurements

Run:

```sh
clojure -M -e '(load-file "experiments/compiler/bench.clj") (klara.compile-bench/run!)'
```

OpenJDK 25.0.1, Clojure 1.12.4. Four functions loop over input 200.
Each path warms up for 100 calls, then reports the median of seven batches
of twenty calls (milliseconds per call). Compiled execution includes
T0 entry, cache lookup and guards. Compilation is the median of five
compilations per definition, including analyses and Clojure `eval`.
The script checks result equality before timing. Construction counts are
static eliminated sites, not measured bytes or JVM allocation counts.

This table is the final sample, taken after the test process finished.
Earlier samples ranged from roughly 28× to 131×; this variation is why

These are exploratory measurements in a shared development environment,
not isolated performance claims. Different JIT warmup, heap pressure,
process scheduling and input sizes can substantially change the ratios.
No confidence intervals, allocation profiler or break-even policy is supplied.

## Explicit design decisions

1. **Named K1.** Use fresh symbols after K0 to make substitution simple;
   source CodeIds remain unchanged. Generated names are not stable content
   hashes. Stable pass caching/self-hosting remains future work.
2. **Handler evidence.** Infer a small structural subset instead of trusting
   unchecked operation declarations. Tail clauses must have a direct final
   continuation application; more elaborate tail-shaped clauses may be
   conservatively classified general. No general continuation crosses a
   compiled JVM frame.
3. **Compilation region.** Compile an entire supported definition or reject
   it. There are no mixed T0 islands inside emitted bodies. Dead branches
   can disappear before emission, including unreachable unsupported forms.
4. **Global references.** Only guarded inlining of eligible world functions
   is emitted. Remaining global references are refused, rather than being
   resolved through a shared host namespace. A generic basis-aware call
   ABI is still needed for full T1 coverage.
5. **Exception resumption.** Guard out dynamic exception handlers at entry.
   A compiled JVM frame cannot reconstruct T0's continuation after a failed
   primitive. Never replay after effects have begun.
6. **Authority ABI.** Direct store operations use existing `*outer-k*`
   frames. Frame-creating authority operations remain T0; there is no new
   store, bypass or duplicated split/settlement implementation.
7. **Numeric conservatism.** No unguarded identities such as `x + 0 → x`:
   wrong types, coercions, overflow, floating-point signed zero and NaN
   prevent treating mathematical identities as untyped Klara laws.
8. **Definition-time recording.** An inlined world read is still a runtime
   recorded read when a compiled call computes a new definition value.
   The wrapper records these dependencies conservatively, even if an
   optimized branch does not consume every one.
9. **Allocation strategy.** All-or-nothing replacement of a locally observed
   allocation. Keep every field computation in order. Do not use liveness
   alone to infer uniqueness or authorize mutable storage.

## Gaps and decisions still open

- Full generic T1 calls/global lookup, higher-order/host calls and escaping
  closures need a basis/context ABI and a precise continuation boundary.
  They are rejected rather than wrapped in T0 and mislabeled compiled.
- General operations, dynamic handlers, return clauses and broader
  structural tail classification remain T0. Selective continuation-passing
  conversion is not implemented in S8.
- Variadic functions, mutual recursion and non-tail recursive calls are
  refused; no general tail-call dispatcher exists in this backend.
- `fork`, `direct`, `use`, `adopt`, host/world/staging operations remain T0.
  The compiler does not emit fork control or generated staged code.
- Boxed intermediates are **not** unboxed. Maps require literal keyword
  keys and recognized present-key `get`; vectors require known in-range
  projections. Vector `get` additionally requires Long/Integer keys for
  replacement: Short/Byte keys are absent even though `nth` accepts them.
  Boxed-key differential tests cover this distinction. These restrictions
  avoid changing runtime failure behavior.
- Partial escape analysis is the next extension: an allocation escaping on
  one path currently blocks replacement on every path. No buffer reuse,
  ownership optimization or allocation profiler is implemented.
- Passes are host Clojure functions over values, not world-published Klara
  definitions. No persistent incremental pass cache, stable named-IR hash,
  hotness policy, automatic recompilation, K3 bytecode emitter or native
  backend exists. Raster's bytecode emitter was not integrated.
- Certificate strengthening and an independently evaluated residual
  semantics remain open. Differential tests are finite evidence and do
  not establish a proof for arbitrary programs.
