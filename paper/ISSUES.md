# Discussion issues exposed by the paper

Snapshot: `0831749af6a4f72e82501b26feef268ac1ec4b98` (S11), 2026-10-28. These are observations and proposed questions, not approved design changes. Only small prose corrections in `doc/` were made. No RFC, runtime, test, example, spec, or sibling worktree was changed.

## Corrected directly

- `doc/semantics.md` §3: the operation rule used successive indices 0, 1, 2. `handleEff` actually substitutes at 0 three times, lowering indices each time, and injects the operation tag as an integer literal. This is a semantic transcription error, not a new rule.
- The same document described authority restrictions as not enforced. T0 S6/S10 enforce them; the small-step core does not model them.
- The values/configurations section now scopes `isVal` to ordinary values and says world entries are closed **terms** under `WSW`; the counter supplies both handler labels and generated names. Freshness is not part of `WSC`.
- Guide 01 incorrectly said staging was absent from the formal spec; S5 added it.
- Guide 04's “forking costs nothing” now says it shares the root rather than copying all definitions; this does not claim zero allocation.
- Guide 05 now says `run` evaluates in T0, generator equivalence is an obligation, and safe early let-insertion needs termination/failure preservation as well as purity. Its authority note now distinguishes conservative lift refusal from authority-aware staging.
- Guide 06 now distinguishes S3's entry guards/pure replay from S7–S11's supported mid-body frame reconstruction.
- Guide 07 distinguishes implemented explicit resource wrappers from unimplemented automatic wrapping/branchable host atoms.

## Highest-priority research gaps

1. **The central authority claim is outside the proof boundary.** `spec/` has no authority store, generation, branch-context derivation, owned loans, intent queue, or settlement. Define a sequential configuration extension and conservation/stale-use theorem before claiming verified fork safety. Fail-closed incomplete settlement is not recovery or progress; aborted continuations can retain leases. Concurrent multi-system atomicity is another problem.
2. **RFC 0005's algebra table is a sketch.** Random splitting does not specify a partial commutative recombination; tradable budget components may become negative despite the stated nonnegative carrier. Owned mode matters independently of fraction: a full read loan is not write permission. An Iris-style model needs validity, authoritative state, generations, provenance, and lifecycle transitions—not just a sum of shares.
3. **Moving authority checks requires stability of authority state.** Root-keyed world validity is sound for immutable definitions; it cannot alone memoize uniqueness in mutable Σ. State precisely which lease/invariant licenses moving each check to entry. Prove the static checker's soundness and a representation relation for erased boxes/arrays.
4. **Scoping is weaker than hygiene/freshness.** `WSW` closes world terms but does not require values; `WSC` does not bound generated names or capabilities by the counter. Generated variables are always well-scoped in the de Bruijn predicate. Prove the reachable-state freshness invariant before a universal capability-uniqueness or hygiene claim. Binder-general `run-quote` is open; `isVal` excludes built code values.
5. **The denotational model is not yet constructed.** The paper defines only finite first-order trees and a discrete measure fold. Scores above 1 require nonnormalized measures, not subdistributions. Higher-order recursion, nominal labels, intensional code, changing worlds, and authority need further models. The paper's adequacy statement is a conjecture; its pure big-step equivalence is a new unmechanized proof sketch.
6. **Spec/T0 agreement is partial.** The 69-case corpus has four named expected differences. Closure observations collapse all functions to a marker. Reconcile CSP and errors, or define an explicit relation. Audit mathematical Int versus Long overflow; no runtime reproduction was attempted here. Kernel proofs do not verify the executable ansatz bridge or T0.
7. **Certificate boundaries need consistent terminology.** Fusion equations are kernel-checked; elaboration, lowering, Init import, and overflow coincidence remain trusted. Affine derivations are checked by an implemented checker, not an ansatz soundness proof. Compile-tier certificates are not interchangeable with kernel equality proofs. Independent upstream Lean rechecking would strengthen confidence in the proof artifacts.
8. **Evaluation needs a submission-quality protocol.** S11 microbenchmarks are feasibility evidence, not confidence-bounded speed claims. Preserve the tail-effect regression and the 14.5× full-entry overhead of the long-warmed small loop. Add independent process runs, machine details, realistic workloads, forced-deopt traces, edit latency, and retained-memory measurements. Keep selection/training feedback separate from evidence used to claim speedup.

## Specific follow-ups for docs and design owners

- **Spec README drift (outside authorized edit paths):** sections still describe the old `run1` proof induction/value converse and older corpus counts; S5 uses level-indexed `ev-ok`, and `isVal` no longer characterizes every staged value. Reconcile the “five source-level additions” wording with actual constructors.
- **RFC 0002 / architecture history:** entry-only guards and replay descriptions are superseded for supported S7/S9/S11 frame states. Retain replay only where justified by pure computation; do not imply arbitrary live host frames can be converted. The Effekt 2020 *Effects as Capabilities* reference is OOPSLA, not ICFP.
- **Historical research notes G/K/M/J:** several “missing” features were implemented by S6–S11; dynamic-handler descriptions predate the lexical decision, and suggestions to invalidate facts on publication differ from the implemented immutable-root memo. Date these statements rather than treating all notes as current specification.
- **`lift` and basis preservation:** reconstructed closures may run with a different basis from the original closure; opaque host functions and cyclic closures can retain host identity. Conservative resource refusal is not a serialization or authority-preservation theorem. Metadata/opaque capture behavior needs an explicit contract.
- **`genlet` with control:** mutable loci accumulate bindings across multiple resumptions. Hoisting a pure diverging or failing expression changes behavior, as can moving it out of a conditional. Decide whether to constrain, certify, or document each generator obligation.
- **World publication:** automatic dependency repair is a REPL policy, not the primitive publish operation. Host reads during macro expansion are not recorded; retrying a CAS can repeat definition-time effects. Define which expansion/publication effects are legal.
- **Host isolation:** explicit `fork` defers classified irreversible calls; fork-resume does not automatically defer them. Raw host atoms are shared. Clarify the intended coverage rather than describing universal transactional isolation. Branchable system support in Klara currently covers worlds, not every Datahike/Spindel adapter named by the design.
- **SMC example robustness (not changed):** `examples/klara/07-smc.md` tests `(:done (first ps))` as a truth value, but `:done` can contain a false model result. Inspect completion by key presence or a distinct tag. Also define zero-total-mass and mismatched observation-boundary behavior. The recorded seed's successful transcript does not establish general correctness.
- **Example prose (not changed):** `examples/staging/01-power.md` calls `run` compilation, although this snapshot evaluates through T0. Some guide/example lines have surplus closing parentheses; the paper's power application is balanced and labeled as a normalized transcription. Preserve transcript runner conventions when repairing them.
- **Code identity and nominal types:** SHA-256 cannot be injective on all syntax. Separate canonical alpha-equivalence from digest collision assumptions. RFC 0007's generative seals cannot be implemented merely by structural hashes.
- **λ∨ relationship:** Lean no-double-counting and Redex results concern a different calculus. The local ESOP-targeted draft is anonymous and unpublished in the inspected source; confirm authorship, public availability, and submission status before replacing the project-level citation. No acceptance is claimed.
